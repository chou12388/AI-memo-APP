# Memo Garden

Memo Garden は、Flask で作成したシンプルなメモ管理アプリです。

メモの登録・検索・編集・削除のほか、音声入力や AI を利用した ToDo リストの作成に対応しています。

## 主な機能

- メモの新規登録
- メモの検索と並び替え
- メモの編集と削除
- 日本語・中国語の音声入力
- AI によるメモの整理
- AI による ToDo リスト作成
- ダークモード表示

## 必要な環境

- Windows 10 または Windows 11
- Python 3.10以上（3.11推奨）
- インターネット接続（初回セットアップおよび AI 機能の利用時）

## 起動方法

1. GitHub の「Code」から「Download ZIP」を選択します。
2. ダウンロードした ZIP ファイルを展開します。
3. 展開したフォルダー内の `メモアプリを起動.bat` をダブルクリックします。
4. 初回起動時は、仮想環境の作成と必要なパッケージのインストールが自動で行われます。
5. セットアップ完了後、ブラウザで Memo Garden が開きます。

既存の `.venv` が古いPythonで作られている場合や必要パッケージが不足している場合は、起動スクリプトが自動で再構築します。ポート5001で起動済みの Memo Garden がある場合は、前のプロセスを終了して再起動します。別のアプリがポート5001を使用している場合はエラーを表示します。

通常は次のアドレスで利用できます。

<http://127.0.0.1:5001>

## AI 機能について

AI 機能を利用する場合は、画面から利用するサービスとモデルを選択し、自分の API Key を入力してください。

入力した API Key はサーバーやデータベースには保存されません。ブラウザのタブまたはブラウザを閉じると削除されます。

## データについて

- メモは `memo_app/memo.db` に保存されます。
- `memo.db` は初回起動時に自動で作成されます。
- アプリを更新する場合は、既存の `memo.db` をバックアップしてください。

## セキュリティ

- API Keyは画面から入力し、ブラウザの `sessionStorage` だけに保持します。
- メモ削除は確認後のPOST送信とCSRFトークン検証で保護します。
- `.env.example` を `.env` にコピーして `SECRET_KEY` を設定すると、再起動後も同じ会話セッション設定を利用できます。`.env` はGitへ登録されません。

## 手動で起動する場合

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python memo_app\app.py
```

Python 3.10以上を使用してください。

## 終了方法

アプリはバックグラウンドで動作します。もう一度 `メモアプリを起動.bat` を実行すると、前回のプロセスを終了して再起動します。完全に終了する場合は、Windowsのタスクマネージャーから、コマンドラインが `memo_app\app.py` の Python プロセスを終了してください。

## テスト

```powershell
.venv\Scripts\python.exe -m pytest -q
```
