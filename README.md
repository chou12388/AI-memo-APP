# Memo Garden

Memo Garden は、Flask で作成したシンプルなメモ管理アプリです。

メモの登録・検索・編集・削除のほか、音声入力や AI を利用した ToDo リストの作成に対応しています。

## 主な機能

- メモの新規登録
- メモの検索と並び替え
- メモの編集と削除
- 日本語・中国語の音声入力
- AI によるメモの整理
- AI による ToDo リスト作成
- ダークモード表示

## 必要な環境

- Windows 10 または Windows 11
- Python 3
- インターネット接続（初回セットアップおよび AI 機能の利用時）

## 起動方法

1. GitHub の「Code」から「Download ZIP」を選択します。
2. ダウンロードした ZIP ファイルを展開します。
3. 展開したフォルダー内の `メモアプリを起動.bat` をダブルクリックします。
4. 初回起動時は、仮想環境の作成と必要なパッケージのインストールが自動で行われます。
5. セットアップ完了後、ブラウザで Memo Garden が開きます。

通常は次のアドレスで利用できます。

<http://127.0.0.1:5000>

## AI 機能について

AI 機能を利用する場合は、画面から利用するサービスとモデルを選択し、自分の API Key を入力してください。

入力した API Key はサーバーやデータベースには保存されません。ブラウザのタブまたはブラウザを閉じると削除されます。

## データについて

- メモは `memo_app/memo.db` に保存されます。
- `memo.db` は初回起動時に自動で作成されます。
- アプリを更新する場合は、既存の `memo.db` をバックアップしてください。

## 手動で起動する場合

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python memo_app\app.py
```

## 終了方法

アプリを起動したコマンド画面で `Ctrl + C` を押すか、コマンド画面を閉じてください。
